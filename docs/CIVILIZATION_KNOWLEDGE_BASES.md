# Civilization Knowledge Bases — Monolith_v2

The file explorer includes a Knowledge Library with collections for mathematics of other civilizations, astronomy, physics, symbolic languages, communication archives and research records.

Agents may create, import, index, search, annotate and version collections, with source attribution, provenance and access control. Supported formats planned: JSON, CSV, SQL exports, PDF, plain text, images and LaTeX.

Every record must distinguish verified evidence, user-supplied material, hypothesis, simulation and AI-generated content. Never claim extraterrestrial origin or authenticity without verifiable evidence.

The chat and terminal can query collections through authenticated APIs. Mathematical notation renders as LaTeX with responsive sizing. Include backups, export, audit history, and protections against untrusted files and executable content.

Status: specification only; implementation pending.
