# Binary knowledge storage

Civilization knowledge bases may be opaque binary blobs; the user does not need to see their raw contents in the explorer.

Explorer displays only name/identifier, size, detected format, source, checksum, timestamp, analysis status and provenance confidence. Raw bytes are stored separately with access controls, integrity checks, backups and versioning.

AI workers may ingest and index binary payloads, detect known formats, attempt safe decoding and analyze patterns. Unknown encodings stay marked unknown. Untrusted binaries are never executed automatically; parsing runs in a sandbox with resource limits.

Communications gateway can ingest binary payloads with verified source metadata. Do not assert extraterrestrial origin or successful decoding without evidence. Keep audit trails and allow authorized export or inspection when needed.

Status: specification only, implementation pending.
